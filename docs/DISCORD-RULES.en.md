# Windows GPU UNLOCK — Community Rules

Welcome! This server is a space to meet contributors, exchange ideas, share small findings, and explore development and research together.

1. **Keep important work on GitHub.** Use GitHub issues and pull requests for substantial research results, reproducible test reports, code review, and project decisions. Summarize useful Discord discussions there and link back to the relevant issue or PR.

2. **Share work in progress openly.** Questions, early ideas, small experiments, and partial findings are welcome here. Clearly distinguish observations, hypotheses, and confirmed results.

3. **Give useful context.** When sharing a finding, include the relevant GPU/system, source version, test conditions, and limitations when known. Use GitHub for detailed logs and reports. One machine's success does not establish support for every card of that model.

4. **Respect each other and their time.** Discuss ideas constructively. No harassment, personal attacks, spam, or repeated demands for support. Participation and testing are voluntary.

5. **Protect private and proprietary information.** Review and sanitize logs before sharing. Do not post passwords, tokens, recovery keys, personal identifiers, or proprietary firmware/driver dumps.

6. **Do not pressure others into risky tests.** Never ask someone to bypass hardware checks or run an unreviewed EFI just to provide a result. A file shared on Discord is not automatically reviewed or approved by the project.

7. **Keep collaboration traceable.** Credit sources and contributors, respect licenses and attribution preferences, and link to the original work. Discuss proposed changes here, then submit them through GitHub for review.
